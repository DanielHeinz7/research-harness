The `research-harness` plugin is now installable: the repo carries a marketplace
manifest that lists it, the plugin declares its fixed identity (name
`research-harness`, version 0.1.0, MIT), and `hooks/hooks.json` exists as an
empty skeleton the later hook tasks fill in. A test keeps the description and
version from drifting between the two manifests and asserts that the plugin
ships no `commands/` directory, because its slash commands are skills.
