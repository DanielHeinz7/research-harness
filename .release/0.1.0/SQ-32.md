---
ref: SQ-32
title: CLI-named path operands no longer trigger the Bash guard
bump: patch
plugins:
  - research-harness
---

A path whose final component is `research-harness` is now treated as a path
operand rather than a CLI invocation. Ordinary repository commands such as
`cd`, `mkdir`, and `git -C` no longer receive the guard's read-only refusal
merely because they name the checkout. Direct CLI calls, runner invocations,
and `xargs research-harness accept` remain protected.
