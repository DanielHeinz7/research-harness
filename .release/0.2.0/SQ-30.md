title: The element status line names what it counts
bump: patch

The session summary and `status` used to render an element that holds only
proposals as `1 open (+1 open)`, the status word and the proposal count
spelled the same way. The count now says `proposal` or `proposals`, and an
open element takes no plus sign because there is nothing committed to add
to: `1 stated (+1 proposal) · 2 open (1 proposal)`.
