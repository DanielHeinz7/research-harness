title: The review report counts proposals the way the session summary does
bump: patch
plugins:
  - research-harness
---

`review` built its own element status line and still printed an element
that holds only proposals as `2 Literature: open (+1 open)` after the
session summary and `status` had moved to `2 open (1 proposal)`. The
review report now uses the same wording: the count says `proposal` or
`proposals`, and an open element takes no plus sign.
