ref: SQ-52
title: The Bash guard follows launchers and reads program text
bump: patch
plugins:
  - research-harness
---

`research-harness accept` could be run from the shell behind any launcher the
guard did not know: `env`, `command`, `exec`, `nice`, `time`, `nohup`, `sudo`,
`xargs` with a runner in its command slot, `find -exec`, and program text
carried by `sh -c`, `bash -c`, `zsh -c`, `eval` or `node -e`. The guard now
follows a launcher to the command it runs, however many are stacked, and judges
a program text it cannot lex by what it names: a CLI name as a path component
or a `require`/`import` target, or the word `accept`. A leading environment
assignment is refused along the same routes.

Ordinary work is untouched: `env FOO=1 npm test`, `sh -c 'ls research'`,
`node -e 'console.log(1)'` and `cd research-harness && npm test` still pass.
