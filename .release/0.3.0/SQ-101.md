---
ref: SQ-101
title: A heredoc program for python, node, perl or ruby is no longer read as shell
bump: patch
plugins:
  - research-harness
---

The guard used to lex a heredoc fed to `python3 -`, `node -`, `perl` or `ruby` as a bash script, so ordinary Python or JavaScript source could be refused as a shell command that touches research state. It now judges that body the way it judges the same text under `python3 -c` or `node -e`: by the state paths it names. A heredoc fed to a shell is still read as the script it is.
