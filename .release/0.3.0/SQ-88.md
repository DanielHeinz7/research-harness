ref: SQ-88
title: Shared write library for accept, log and [stated]
bump: patch
plugins:
  - research-harness
---

The accept and log commands now run on a shared write library in `hooks/lib/`,
which the upcoming session view will call too. Their output and exit codes
are unchanged. A write that names the statement text it saw is refused as
stale when that text changed. A new `setStated` moves a `[proposed]` or
`[tentative]` statement to `[stated]` without a log entry.
