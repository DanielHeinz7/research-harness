ref: SQ-89
title: research-harness serve starts a local session server
bump: minor
plugins:
  - research-harness
---

`research-harness serve [--no-open]` starts a local server for the project's
canvas and decision log. It listens on 127.0.0.1 on a random port and opens the
browser at a URL carrying a one-time token, which it also prints once. The token
lives only in memory. Comments, `[stated]` and accepts from the view go through
the same write library as the CLI. An accept from the view writes the same
decision log as `research-harness accept`. A write without the token, from
another host name or from another origin is refused.
