title: research-harness serve shows a clickable canvas session view
bump: minor
plugins:
  - research-harness
---

The local session server (`research-harness serve`) now serves a full canvas
view at its root: a 3x3 zoom-out grid of the nine canvas elements with
per-element marker counts and an accent on the open element most others
depend on; a zoom-in per element with numbered questions, statements shown as
footnotes resolved through a per-element source key; an agenda pairing open
elements with their linked findings; a decision log with seal status per
entry; and print CSS for a landscape grid page plus one page per section.
Comment, `[stated]` and accept actions are available directly from the view
and go through the same write path as the CLI.
