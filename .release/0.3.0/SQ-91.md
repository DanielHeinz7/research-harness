---
ref: SQ-91
title: The guard stops the model starting the session server
bump: patch
plugins:
  - research-harness
---

The session server takes approvals from the browser, so only the researcher
starts it. The promotion guard already refused `research-harness serve`; it now
also refuses running `bin/canvas-serve.js` directly, whether through a runner
(`node .../canvas-serve.js`), a wrapper such as `nohup` or `env`, or a program
text (`sh -c`, `eval`, `node -e`) that names `canvas-serve`. Reading the file
is still allowed.
