A second restyled copy of the session view, `dashboard/variants/canvas-b.html`, sits alongside the pilot's document-style `canvas.html`: a persistent rail of the nine elements next to whichever element is in focus, a segmented Agenda/Overview/Decision-log nav, and marker/status chips rendered as word plus shape (never colour alone). Same write behaviour as the original view — the `#c=` code exchange, the in-memory token, `expectedHash` on every write, fixture mode and the escaping are unchanged. Offline, and still prints to A4 with a landscape grid page.
