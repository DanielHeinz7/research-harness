title: Session view is now the poster (variant C)
bump: patch
plugins:
  - research-harness
---

`research-harness serve` now opens the poster view: the whole paper on one
screen, "To talk about", "History", and an element view with "Idea" notes and
page-number sources. A poster card whose field has findings ends with a quiet
"N things to talk about" line that opens that field in the "To talk about" tab.
The paper title appears once, as the large heading. The poster prints on one
A4 landscape page. Variants A and B and the `dashboard/variants/` folder are
removed. README "Session view" and spec section 7 describe the new view.
