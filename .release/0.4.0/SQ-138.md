---
ref: SQ-138
title: Skills no longer pre-approve a `node` route
bump: patch
plugins:
  - research-harness
---

The `check` and `record-review` skills now call the bare `research-harness` command (the plugin's `bin/` shim, which Claude Code puts on the Bash tool's PATH) and pre-approve only fixed-prefix forms: `research-harness status` and `research-harness log DISCOVERY` for `check`, `research-harness review` and `research-harness status` plus the git read verbs for `record-review`. `accept` declares no `allowed-tools` at all. Before, `Bash(node:*)` and `Bash(node *research-harness.js review:*)` let a prompt injection in a source or a log entry run `node -e` against the library and choose or accept without a prompt.
