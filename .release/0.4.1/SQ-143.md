An alternative example, `examples/big-data-communication/`, pins Zenodo record
6344804 (CC BY 4.0): 13 interview transcript PDFs and a participant PDF. Its
fetcher checks size and SHA-256 without storing the transcripts in Git. Three
hand-written, PDF-page-cited variants and a README CLI path let a researcher
try the multiverse, explanation and sealed review on different material. A
short link in the plugin README leaves the primary walkthrough unchanged.
