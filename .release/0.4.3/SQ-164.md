---
title: doctor notices a terminal command your shell cannot find
bump: patch
plugins:
  - research-harness
---

`research-harness doctor` reported the terminal command as installed when it sat
in `~/.local/bin` but that folder was not on your PATH, so typing the command
in a terminal failed. doctor now says so and prints the line to add to
`~/.zshrc`, the same one `install-cli` prints.
