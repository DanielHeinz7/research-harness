---
title: A flag given without a value is refused, not dropped
bump: patch
plugins:
  - research-harness
---

`research-harness accept 1.2 --match` with the value left off accepted the
question's single candidate without checking it against the filter, `init
--profile` took the default profile, and a bare `--title`, `--outlet`, `--why`
or `--rejected` disappeared without a word. A flag that takes a value now exits
2 with `<flag> needs a value` before the command runs, so nothing is read and
nothing is written.
