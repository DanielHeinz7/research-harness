ref: SQ-171
title: A second profile for hypothesis-testing studies
bump: patch
plugins:
  - research-harness
---

The plugin now ships a second canvas profile, `is-quantitative`, for
experiments and surveys that test hypotheses derived from prior theory. It
follows the canvas's presentation order: prior research leads to the question,
the question to the hypotheses, then sample and design.
`research-harness init --profile is-quantitative` starts a canvas on it. A
profile file may also declare the mechanical checks its modules add to the
review; `is-quantitative` declares `hypotheses-before-data`.
