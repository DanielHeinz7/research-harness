title: The session view draws the dependency graph of the active profile
bump: patch
plugins:
  - research-harness
---

The session view no longer carries a copy of the `is-qualitative` graph. It
draws the open field most others depend on from the active profile's adjacency,
which `/api/state` now sends alongside the state; a profile that cannot be
loaded leaves the view with no graph and the profile error it already shows.
The view is therefore correct for any profile the canvas names, not only for
the one it shipped with.
