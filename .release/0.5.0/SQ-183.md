---
ref: SQ-183
title: The session protocol comes out of the CLI
bump: patch
plugins:
  - research-harness
---

`research-harness session protocol [<n>]` prints what one session decided:
the entries from its SESSION marker to the next marker (or the end of the
log), grouped into Accepted, Noted and Open at the end, with the occasion,
the date, the participants, the seal status of the section and the log anchor
as of its last entry. An accepted statement's text is read from the canvas
while its text hash still matches; otherwise the protocol says `text changed
since` with the hash. A broken chain still yields a protocol, headed `BROKEN
at #n`; a log without a marker is refused with a pointer to `session start`.
`<n>` picks a session by its marker's number (`12` and `#12` both work);
without it the latest session is printed, and `--out <file>` writes the
protocol to a file.
