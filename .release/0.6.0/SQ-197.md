ref: SQ-197
title: The plugin suite passes without a machine git user.name
bump: patch
plugins:
  - research-harness
---

Three test files left the `By` name of every entry (SQ-177) to the machine's
`git config user.name`, so the suite was green on a machine with a git identity
and red on CI or a fresh clone. The `demo`, `variants` and `replacement-demo`
tests now write `A. Researcher` into their own `RESEARCH_HARNESS_STATE_DIR`
before the CLI runs, the way the already-fixed tests do. The whole plugin suite
passes with `GIT_CONFIG_GLOBAL=/dev/null GIT_CONFIG_NOSYSTEM=1`; the name
refusal in the code is unchanged.
