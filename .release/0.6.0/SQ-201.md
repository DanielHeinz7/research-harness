# SQ-201: literal paths in a notes-only research directory

The reported false denial could not be reproduced on 0.5.0: SQ-75's
`namesAbsentStateDir` already allows literal note paths when there is no
research state. Only regression tests were added; the guard is unchanged.

The four hook cases cover moving a note into `research/`, editing a note after
`cd repo || exit 1`, refusing a redirect that creates `research/canvas.md`, and
refusing the same note move when `research/` holds `canvas.md`.
