New `hooks/lib/glossary.js` reads `glossary.md` (`glossary-schema: 1`) from the
state directory `stateDirOf` selects, so a variant framing reads its own
definitions rather than the main file's. Entries carry a unique lowercase
hyphenated id, then term, aliases, definition, origin and distinctions once
each, then the authorization marker; duplicate ids or fields, an unsupported
schema, a malformed origin and dangling distinction links are reported with
their lines as unjudgeable, and the raw block stays in the result. `src:`
origins resolve against the project root, refusing traversal and symlinks that
leave it, and an unreadable target is reported as unreadable rather than
absent. The payload an acceptance will bind is canonical JSON of the id and the
normalized field values, marker excluded, so a reflow keeps its hash and any
wording change breaks it. `references/construct-glossary.md` describes the
format. Acceptance, protection and review are separate packages; no command
accepts an entry yet.
