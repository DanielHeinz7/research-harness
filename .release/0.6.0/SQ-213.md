title: Extract paper text locally with a validated printed-page map

A new `scripts/extract-paper.py` turns one local PDF into a full text that keeps every physical page boundary and the raw header and footer lines, a reduced request view, and a page-map sidecar bound to the PDF, extraction and request hashes. A constant offset is accepted only when every physical page carries a consistent, unique and monotonic page-number label; irregular numbering, a missing label, an ambiguous header or a map bound to other bytes refuses automatic printed numbering and asks for an explicit researcher-confirmed map, which may mark pages as unnumbered. Pages without extractable text stay uncheckable rather than guessed, a missing `pdftotext` is a dependency failure and never a passing check, and a changed PDF, map or extraction invalidates the earlier record. `references/literature-note.md` documents the CLI, exit codes and sidecar schema.
