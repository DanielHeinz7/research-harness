Glossary review compares the sealed decision payload with the live definition, so a colliding short identifier cannot hide a changed entry. Acceptance checks for concurrent glossary edits before publication. The acceptance skill explains how to recover an unlogged marker after a crash by resetting it to proposed, showing the entry, and accepting again.
