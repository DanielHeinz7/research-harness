---
ref: SQ-222
title: Refuse link forms and unmarked prose in a drafted literature note
bump: patch
plugins:
  - research-harness
---

Harden the literature draft adapter's response check: a bare `scheme://` URL, a reference `[text][id]` link and an `[id]: ...` definition are refused like an inline link, prose between the H1 and the first H2 must carry the `[proposed]` marker, and every non-blank line of `Quotations` must be a blockquote instead of prose the quotation check never inventories. Match selected-context names case-insensitively and existing state files by inode, so a differently cased name or a hard link to another state's canvas, ledger or glossary can no longer be sent to the gateway. Document both rules in the plugin reference.
