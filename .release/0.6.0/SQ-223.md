bump: patch

The state the README's pictures and the demo video's UI scenes are captured from
now sits in `docs/media/showcase-state.json` and is guarded by a test that mounts
it through the view's own fixture path and fails when a schema change would leave
a screenshot blank or on the view's error or notice path.
`scripts/capture-session-view.js` takes poster, framings, To talk about, History
and field captures at a chosen viewport size with Playwright, and
`docs/media/README.md` says how to run it and where the content comes from. No
runtime behaviour of the plugin changes.
