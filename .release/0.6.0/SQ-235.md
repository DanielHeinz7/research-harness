---
ref: SQ-235
title: Guard blocks the tool call when it times out or crashes
bump: patch
plugins:
  - research-harness
---

The PreToolUse guard now fails closed when Claude Code gets no verdict from it. `hooks.json` sets `"onFailure": "block"` on the guard, so a guard that times out after its 10 seconds, crashes, or cannot start blocks the tool call instead of letting it through. Before, Claude Code counted such a run as a non-blocking error and ran the call unjudged, and on a heavily loaded machine a slow Node start was enough for that. The key needs Claude Code 2.1.295 or later. The guard has no matcher and the plugin is installed for every project, so while the guard cannot answer, every tool call in every project is blocked. SessionStart still fails open.
