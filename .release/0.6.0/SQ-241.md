title: Git module for the desktop app's clone, update and send steps
bump: patch
plugins:

New internal module `hooks/lib/app-git.js` for the coming desktop app. It
clones a shared project, gets updates, commits and sends, always without a
shell and only over https and ssh. Every call returns a result instead of
throwing. A person without a git identity can still commit and merge. A
clone link that would reach git or ssh as an option is refused before git
runs. A merge that stops for any reason other than a conflict is undone, so
no merge is left half done. Nothing user-facing calls it yet.
