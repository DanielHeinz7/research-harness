---
ref: SQ-242
title: The desktop app can run the plugin CLI for one project
bump: patch
plugins:
  - research-harness
---

A new internal module, `hooks/lib/app-cli.js`, runs `research-harness` for the
desktop app against one project folder. It starts the same command line as the
terminal through `execFile` with an argument array and no shell, so the app
takes the same checks and writes the same files. A usage error (exit code 2)
comes back as `invalid`, any other failure as `refused`, each with the
command's own message. Nothing changes for existing commands.
