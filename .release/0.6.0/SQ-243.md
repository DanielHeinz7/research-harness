Two new internal modules for the coming desktop app. `hooks/lib/app-store.js`
keeps a list of recent projects in the app's own data folder. It holds no
token, key or credential. `hooks/lib/app-api.js` holds the app's routes:
list, open, create and clone projects, get updates, send, invite, join, and
start a session or save its minutes. Get updates first commits the person's
own research changes. When both people appended to the decision log, it
merges the two logs with merge-log and commits only a log whose seal
verifies. Any other conflict is aborted, nothing is lost, and the message
names the file both people changed. Nothing user-facing calls these modules
yet.
