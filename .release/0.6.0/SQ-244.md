title: App mode for the session server and serve --app
bump: patch
plugins:
  - research-harness
---

`research-harness serve --app [--app-data <dir>] [--no-open]` starts the
session server in app mode for the coming desktop app. It starts without a
paper project; if the folder it runs in has one, that project is open. It
prints a URL to the app page at `/app` that carries the single-use code, like
the session view's URL. The app's routes live under `/api/app/` and every one
of them needs the write token, reads included. Opening a project there
switches the project the session view's routes act on; until one is open,
those routes answer that no project is open. Recent projects are kept in
`--app-data`, by default `~/.research-harness`. `serve` without `--app` works
as before, and the app page (`dashboard/app.html`) comes in a later change,
so `/app` shows a short placeholder for now.
