---
ref: SQ-245
title: Session view takes its token and tab from the app shell
bump: patch
plugins:
  - research-harness
---

When the session view is embedded in another page of the same origin, it now takes its write token, its tab and its refresh requests from that page by message, and ignores messages from any other origin or window. Opened alone in a browser tab, it redeems its own link code as before.
