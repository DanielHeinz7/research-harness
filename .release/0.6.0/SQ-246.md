The app page (`dashboard/app.html`) replaces the placeholder that `/app`
showed in app mode. With no project open it offers New project, Open project
and Clone from link, each with one sentence on what it does. With a project
open it shows a sidebar (project name and folder, Get updates, Send my
changes, Open, Clone, New; Meeting with Start session, Agenda and Export
minutes; People with Invite co-author, and Join this project where the
machine holds no key) around the session view, which it receives its token
from by message. Each dialog says what it will do before it does it. Outcomes
and errors appear in a line under the control that caused them and stay until
the next action. In a browser tab, where no host bridge exists, the dialogs
ask for typed paths; the Electron app will add `window.harnessHost` pickers.
The page keeps the token in memory only and meets the session view's bar:
keyboard operation, visible focus in light and dark, reflow at 320 px.
