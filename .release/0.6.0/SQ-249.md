ref: SQ-249
title: merge-log merges two logs that started from the same empty log
bump: patch
plugins:
  - research-harness
---

A project shared while its decision log was still empty, after which both people logged, could not be merged: `merge-log` refused because the two logs shared no entry, and Get updates in the app reported a failed merge. `merge-log` now merges such logs when both have the same text above #1 and both start with an entry sealed under the project key. Logs from another project, sealed under another key, or starting with an unsealed entry are still refused.
