The SessionStart summary now carries a line naming the open proposals by
statement number — `Open proposals by number (cite statements as 3.1 or 3.1b):
1.2b, 2.2` — capped at 20 numbers so the hook stays inside its 4 KiB budget.
The numbering (a statement takes its question's id, further statements of the
same question get b, c) now lives in `hooks/lib/numbers.js`, and a test pins the
session view's inline copy of `statementNumber` to the same text. The canvas
skill states the scheme in one line.
