---
ref: SQ-252
title: The session view reveals and looks up a statement by number
bump: patch
plugins:
  - research-harness
---

The session view answers two new messages from the shell, same origin and from
the frame's parent only, as its existing messages do. `harness-reveal` switches
to the poster tab and scrolls the statement `#st-<number>` to the centre and
focuses it; the view now scrolls and focuses through one shared helper, so a
`#st-3.1` link opens the page on the same statement the same way.
`harness-lookup` answers `harness-lookup-result` with the statement's first
eight words followed by ` …` when there are more, or `null` when no visible
statement carries that number: hidden statements are not shown, so they are not
found.
