ref: SQ-105
title: Accept through python -c or an interpreter heredoc is refused in every project
bump: patch
plugins:
  - research-harness
---

`node -e` could never run `research-harness accept`, but `python3 -c`, `perl -e`, `ruby -e` and a heredoc fed to `python3`, `node`, `perl` or `ruby` were refused only in a project that already held research state. They are now refused everywhere when their program text names the CLI together with `accept`, or names the session server. A path that only passes through a `research-harness` directory, or the word `accept` on its own, is still allowed.
