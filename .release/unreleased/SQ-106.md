---
ref: SQ-106
title: The guard lets a loop through when its body only reads
bump: patch
plugins:
  - research-harness
---

A `for`, `while` or `until` loop now passes when every command in it is read-only and none of its redirects writes to a file. Two examples that pass: `for f in research/*.md; do head -3 "$f"; done` and `while read -r l; do echo "$l"; done < research/canvas.md`. A loop that writes is still denied, and so is a loop that runs `research-harness accept`.
