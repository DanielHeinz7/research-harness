The plugin can now read a canvas. `hooks/lib/project.js` answers where things
are — project root from `CLAUDE_PROJECT_DIR`, hook stdin `cwd`, or the working
directory, and the state directory from `RESEARCH_HARNESS_DIR` with `research/`
as the default. `hooks/lib/canvas.js` turns `canvas.md` into elements,
numbered questions and statements carrying an authorization marker and evidence
tags. It is pure and collects problems instead of throwing, so a hook can decide
for itself whether to fail open or closed. Element status derives from committed
statements only: proposals are counted as open and never lower a status.

Tests run against `voice-uptake`, the invented example from the project's own
discussion paper — no real study, no real person, no real transcript.
