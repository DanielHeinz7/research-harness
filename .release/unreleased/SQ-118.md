ref: SQ-118
title: `research-harness title <text>` sets the paper's title on an existing canvas
bump: patch
plugins:
  - research-harness
---

`research-harness title "<text>"` sets or changes the paper's title on a canvas
that already exists. It replaces the `title:` line in the canvas frontmatter, or
writes one directly after `project:` where `init --title` puts it, quoted the way
the other frontmatter values are quoted, so a title holding a colon, a quote or
a hash survives a real YAML reader. Every other byte of `research/canvas.md`
stays as it was, and no decision-log entry is written: the title is
presentational. With no argument the command prints the current title, or says
there is none. An empty title is refused, and outside a paper project the
command refuses like `status`.

`init --title` on a canvas that already exists still changes nothing, and its
one line now names the new command instead of a hand edit: `--title was not
applied: research/canvas.md already exists; run research-harness title "<text>"
to set it.`
