title: Skills for the framing multiverse, advisory check questions and a read-only record reviewer

The `canvas` skill gains a multiverse mode: given k lenses it starts one subagent per lens, each running `init --variant <name> --lens "<text>"`, filling its own variant canvas from the same material and running `review --variant <name>`. It ends by telling the researcher to compare and choose; it never runs `choose`. A new `check` skill (`/research-harness:check <n.m>`) reads a statement, its tags and the sources they name, and records each open question as `log DISCOVERY "<n.m> check"`; it never accepts, edits or approves. A new `record-review` skill is a read-only reviewer mode that answers only from the canvas, the decision log, the `review` output (with `--key <file>` for a received record) and git read verbs, cites `#seq` or `n.m` with the text hash, and otherwise says "not in the record". Tests pin the frontmatter, the reviewer's tool grants, `check`'s single write instruction and that no skill tells the model to accept or choose.
