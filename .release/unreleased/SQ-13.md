The harness now knows what genre it is working in. A profile is one Markdown
file in `references/profiles/`: prose that says which elements carry weight and
why, a fenced ```graph block the loader parses into a dependency graph, and a
table of which reading modules attach where. `is-qualitative` ships first —
information systems, qualitative and interpretive work — and states its
commitments as claims a method expert can argue with rather than as settings.
Three of its edges differ from the order in which the canvas presents its
elements (boundaries before sampling, prior theory after the framing, the
framework after the findings); each carries its reason on the page and each is
one line to change, which is the point of putting a genre in a public Markdown
file.

`hooks/lib/profile.js` loads a profile by id, refuses ids that are not plain
lowercase names, and reads the graph. `hooks/lib/review.js` computes the
mechanical half of `canvas-review`: empty elements, elements holding only
proposals, dependency violations, statements with no marker or no evidence tag,
purely conversational `[stated]` statements, acceptances whose recorded text
hash no longer matches the statement, and accepted statements with no entry in
the decision log. It decides nothing that needs judgment — whether two elements
actually contradict each other stays with the skill and the researcher. The
dependency rule is reported, never enforced.
