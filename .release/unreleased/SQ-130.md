The plugin README gains a walkthrough of the three new capabilities on a public
dataset: a framing multiverse under three lenses, a choice between the framings,
a check question and an accept with an explanation despite it, a read-only
review of the record, and verification of the log on another machine with a
released key and the printed anchor. `examples/ai-assistants-interviews/` holds
the demo material: a pinned fetch of 13 CC BY 4.0 interview transcripts (Zenodo
record 22893731, the only version that still carries them; sha256 per file, none
stored in the repository), and three recorded framings that stand in for the
model's part so the printed output is the same on every run.

`test/demo.test.js` reads the walkthrough out of the README, runs every command
in it in order in a temp project, and fails when a printed line differs from the
output shown there. The command table now lists `choose`, `init --variant`,
`--variant` and `--explained`, which the README had left out.
