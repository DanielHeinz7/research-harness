ref: SQ-141
title: Guard research state across symlinked paths
bump: patch
plugins:
  - research-harness
---

The promotion guard now resolves existing symlinks in shell path candidates before deciding whether a command could write to the canvas or decision log. A link made in an earlier shell call can no longer hide a write. New variant state files spelled beneath `research/` are also denied when a symlink would send the write outside that directory.

The perimeter probe now covers those links and indirect `choose` commands. It also records the documented limit for a library path assembled at runtime, without presenting that route as protected.
