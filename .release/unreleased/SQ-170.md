---
title: A saved accept no longer ends in a silent, stale canvas
bump: patch
plugins:
  - research-harness
---

Accepting a statement, or choosing a framing, writes the change and then reloads
the canvas. When that reload failed, the canvas kept showing the old statements
and said nothing: the error went into the dialog, which had already closed. The
failure now shows in the notice bar, so a canvas that did not reload no longer
looks like one that did.
