ref: SQ-177
title: Every entry names who wrote it
bump: minor
plugins:
  - research-harness
---

Every entry the harness writes — a log finding, an acceptance, a chosen
framing, a profile switch — now carries `**By:** <name>` as its first labelled
line, sealed with the rest of the body. Set the name once for the machine with
`research-harness name "A. Researcher"`; without it the name comes from
`git config user.name`, so an existing checkout needs nothing new. `research-harness name`
without an argument prints the name in use and where it came from.

A machine with neither a name nor a git identity refuses every write instead of
writing an entry no one is named in, with the one command that fixes it.
`research-harness doctor` reports the same before a write runs into it. The name
is a statement, not proof: whoever holds the sealing key can write any name, and
the seal only keeps it from changing afterwards.
