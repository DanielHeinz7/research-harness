---
ref: SQ-199
title: A glob over many ordinary files no longer counts as reaching a key file
bump: patch
plugins:
  - research-harness
---

The key-file check refused shell commands whose glob matched more than 4096
files, such as `ls mail/*/*.md` or `du -ch binlog.*` in a large directory,
because it counted that many matches as reaching an exported `.seal.key` file.
The files a glob's last part matches are now checked by name, so a key among
them is still refused and ordinary files are not. A glob whose directory part
fans out past 4096 directories still counts as reaching a key.
