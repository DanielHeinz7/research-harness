title: Fix session view keyboard navigation and semantics
bump: patch
plugins:
  - research-harness
---

View links identify the current page, headings follow the reading hierarchy,
and the skip link reaches the current content. Accept and framing-choice dialogs
associate errors with the required field and retain native Escape and focus
return. Inline notes identify their errors; saving a note or marking a statement
as said returns focus to the field. At narrow widths, the field rail sits below
the selected view. Colours and spacing use shared tokens; cards no longer have
both borders and diffuse shadows.
