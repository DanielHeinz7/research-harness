title: Playwright is a dev dependency, so the rendered tests and captures run without NODE_PATH
bump: patch
plugins:
  - research-harness
---

The repository root now has a `package.json` whose only `devDependency` is
`playwright`; the plugin itself still ships no dependencies. After
`npm install && npm run setup:browsers`, the browser-rendered tests in
`plugins/research-harness/test/` and `desktop/test/` and
`scripts/capture-session-view.js` find Playwright by walking up to the root
`node_modules`, from anywhere in the repository and with no `NODE_PATH`. They
still skip (tests) or exit with the install hint (capture) when it is missing.
