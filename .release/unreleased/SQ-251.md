ref: SQ-251
title: The SessionStart hook writes the desktop app's session marker when asked
bump: patch
plugins:
  - research-harness
---

When `RESEARCH_HARNESS_APP_MARKER` names an absolute path, the SessionStart hook
writes `{ pluginRoot, version, pid }` to it before anything else, atomically, so
the desktop app can show that the plugin's hooks are loaded in the session. It
is written even in a folder without `research/canvas.md`. Without the variable
the hook's output is byte-identical to before, and a marker path that is
relative or unwritable is ignored — the hook never stops a session over it.
