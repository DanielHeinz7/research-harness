The app's human steps now work for a person with no terminal and an empty home folder. New project… asks for "Your name" (prefilled with the name this computer already has) and stores it the way `research-harness name` does; Start session… asks for it only where the computer has none. New project also turns the folder into a git repository with one commit of the research files. While a project has no shared copy, the sidebar offers Share with co-authors… instead of Get updates and Send my changes: paste the https link of an empty repository and the app uploads the project, refusing a repository that already holds files and changing nothing in that case. Join this project… now shows whenever this computer has no key for the project, also when the decision log is still empty, and sits at the top of the sidebar with a line saying so; Invite co-author… is hidden until the key is here. Before joining, an action that writes an entry answers "Join this project first" with where the key file comes from, and never creates a key. Invite co-author… shows the project's link next to the key file, and its outcome repeats both. Every git failure from Get updates, Send, Share and Clone now reads as a sentence with the next step, with git's own line as a detail; no message in the shell names a terminal command. A dialog's earlier field error clears when the person submits again. Seal chain, log format and guard are unchanged.
