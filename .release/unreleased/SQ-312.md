`hooks/lib/host.js` collects what differs between Windows and the other
systems as pure functions: tidying a typed or pasted folder path, spotting a
folder inside OneDrive, the Node and Git start notes, and the Windows answers
for `install-cli` and a missing Git. Nothing calls it yet; the app routes and
the shell page start using it in the next tasks.
