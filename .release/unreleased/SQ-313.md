ref: SQ-313
title: The app's server side knows about Windows
bump: patch
plugins:
  - research-harness
---

The app's routes now tidy a pasted or typed folder path (spaces, quotes from
"Copy as path") before they check it, answer with the computer's platform,
home folder and path separator, and refuse a New project or Clone inside a
OneDrive folder on Windows; Open warns instead. `serve --app` prints, after the
link, a line that Git was not found (when it was not) and a line that the
window must stay open, and refuses Node.js older than 22. On Windows
`install-cli` says to start research-harness with `Start research-harness.cmd`
instead, and a missing Git names Git for Windows. Nothing changes on macOS and
Linux except the keep-open line.
