bump: patch

  - research-harness

Opened in a browser tab (Windows or not), the app page now starts its folder
fields in the home folder and says, under each of them, how to copy a path:
Copy as path in File Explorer, Option+Command+C in Finder. After Export minutes
or Invite co-author the saved path comes with a Copy path button. Opening a
project inside a OneDrive folder works and says what to do if git misbehaves. A
link that was already used names the way to start again: double-click Start
research-harness on Windows, Ctrl+C and a new start in a terminal elsewhere. The
desktop app is unchanged.
