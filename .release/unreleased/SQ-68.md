---
ref: SQ-68
title: The Bash guard reads an unresolved substitution as a write target only where the verb writes it
bump: patch
plugins:
  - research-harness
---

SQ-57's fail-closed backstop asked one question of every argument word: does it
carry a command substitution the guard could not resolve to a literal? A word
that did became an unknown target and the command was denied. That reading
belongs to a verb whose operand is the file it writes. Asked of every verb, it
refused ordinary work in a paper project:

    mkdir -p "build/$(date +%F)"        denied because `mkdir` is not read-only
    [ "$(sysctl -n vm.loadavg)" = x ]   denied because `sysctl`, inside the
                                        substitution, is not read-only

Neither command names the state. One creates a directory beside it; the other
computes a value.

`NON_FILE_VERBS` is the one new definition — `[`, `test`, `true`, `false`,
`echo`, `printf`, `date`, `sleep`, `mkdir`: verbs whose operand is only ever a
value, never a file they write. The unknown-substitution reading is lifted there
and nowhere else, so every other verb keeps SQ-57's fail-closed answer. `mkdir`
is on the list because every form of it on a path that already exists fails
(EEXIST, or ENOTDIR through a file), so an existing state file keeps its bytes,
mode and mtime. A `mkdir` whose operand names the state literally still denies,
and it is the state check that refuses it, not this one.

Costs and boundaries, named so they are not rediscovered as holes:

- `node script.js "$(git rev-parse HEAD)"` still denies. `node` is not on the
  list, and the literal `node script.js research/canvas.md` already denies on
  main, so the unresolved form has to deny with it.
- Redirect targets are judged exactly as before.
- `vim "$(cat t)"` and `chmod 000 "$(cat t)"` still deny; their literal forms do
  too.

`test/guard-promotion.test.js` gains two cases: ten ALLOW rows (the two reported
over-denials, the other members, and `git commit -m "$(cat msg.txt)"`) and
fourteen DENY rows (the ticket's six plus `mv`, `ln`, `touch`, `truncate`,
`tee`, `dd of=`, `sed -i`, `sort -o`). Reverting the hook fails the ALLOW case
with an `AssertionError`. `verification/SQ-29/lex.txt` L15 still denies, and
probe-lex (34 rows), probe-perimeter (19 rows) and probe-baseline move no row
against HEAD's own hook.
