---
ref: SQ-96
title: Guard no longer reads a `**/` in a sed or grep pattern as the state directory
bump: patch
plugins:
  - research-harness
---

The promotion guard treated a bare `*`, `**` or `?` inside a sed program or grep
pattern as a glob, so it matched the state directory's own name. An edit such as
`sed -i '' 's|x|**/_raw-model-output/*|' .gitignore` was refused even though it
never touches `research/`. Slash-bearing runs inside such text are now compared
literally. Commands that run their text as a shell program (`sh -c`, `eval`,
`bash -c`, interpreters) still treat it as a pattern.
