---
ref: SQ-99
title: Guard refuses accept and serve behind any wrapper
bump: patch
plugins:
  - research-harness
---

In a project with research state, the promotion guard now refuses a shell line that names the CLI together with `accept` or `serve`, or names `canvas-serve`, whatever wraps it. That covers `caffeinate`, `timeout`, `python3 -c`, `osascript -e`, `tmux`, quote-split names under `bash -c` and similar launchers. A line made only of read-only commands, such as `grep accept …`, still passes. A name the command builds at run time is not seen.
