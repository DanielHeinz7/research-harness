# research-harness

Ein Research Harness für das Steuern von Paper-Projekten: Software, Verfahren,
Aufzeichnungen, Checks und Entscheidungsrechte für AI-gestützte Forschung.

**Stand:** Ordner angelegt, Implementierung noch nicht entworfen.

## Wo was liegt

| Ebene | Ort |
|---|---|
| Vorhaben, Entscheidungen, Status | `~/dh-hq/vault/areas/research-harness.md` |
| Diese Implementierung | dieses Repo (öffentlich auf GitHub geplant) |
| Das Paper *über* Research Harnesses | Vorhaben `research-harness-paper` — eigenes privates Repo `~/dh-appdev/research-harness-paper`, Dokumente in `~/dh-projects/research-harness-paper` |

Das Paper ist ein eigenes Vorhaben mit eigener Frist. Dieses Repo endet nicht mit
der Einreichung; es ist das Werkzeug, nicht der Gegenstand.

Der erste Prototyp der Idee (Manuskript-als-Git-Repo, Sidequest-Writing-Profile,
Oracle-Gate als menschliches Qualitätsurteil) liegt als gelebte Instanz im
Paper-Repo und ist die Vorlage, aus der hier ein verallgemeinertes Template
abgeleitet wird.
